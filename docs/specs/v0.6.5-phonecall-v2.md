# Live2D 实时语音模式 UI 设计需求（精简版）

## 一、设计目标

当前 APP 核心是 Live2D 虚拟角色陪伴，语音模式不是独立电话页面，而是**聊天输入框的一种状态切换**。

设计原则：

* 最大化保留 Live2D 角色展示区域
* 不新增大面积语音面板
* 不遮挡角色身体和动作区域
* 字幕位置保持普通聊天模式一致
* 底部仅增加一行实时语音控制栏

整体视觉优先级：

```
Live2D角色 > 字幕 > 语音状态动画 > 控制按钮
```

---

# 二、整体布局

页面结构：

```
┌──────────────────────┐
│                      │
│                      │
│                      │
│      Live2D角色       │
│                      │
│                      │
│                      │
│                      │
│    字幕显示区域       │
│                      │
├──────────────────────┤
│ 🎙️        动态粒子       ❌ │
└──────────────────────┘
```

底部语音栏：

* 高度与普通输入框保持一致
* 固定底部
* 不向上扩展
* 不覆盖 Live2D

---

# 三、底部控制栏设计

## 1. 左侧：麦克风按钮

状态：

开启：

```
🎙️
```

表示：

* 当前可以接收用户语音

关闭：

```
🔇
```

表示：

* 麦克风关闭
* 不采集声音

---

## 2. 中间：语音状态动画（核心）

不采用传统音量柱、跳动条。

采用：

**中心粒子 + 扩散收缩动画**

基础形态：

```
       ·

     · ● ·

   · · ● · ·

     · ● ·

       ·
```

动画逻辑：

```
小范围
 ↓
扩散
 ↓
收缩
 ↓
恢复
```

类似呼吸灯效果。

---

# 四、不同状态动画

## 1. 等待用户讲话

状态：

```
🎙️        · · ● · ·        ❌
```

效果：

* 中心点缓慢呼吸
* 外围粒子轻微出现/消失
* 周期约 1.5~2 秒

表现：

“角色正在等待你的声音”。

---

## 2. 用户讲话中

状态：

```
🎙️      · · ● · ·      ❌
```

效果：

根据麦克风输入变化：

声音小：

```
   · ● ·
```

声音大：

```
 · · ● · ·
· · · ● · · ·
```

但限制：

* 不做快速跳动
* 不做柱状波形
* 保持柔和扩散感

---

## 3. AI播放中

状态：

```
🔇       · · ● · ·       ❌
```

效果：

* 粒子扩散速度提高
* 动画频率提高
* 表示 AI 正在输出声音

支持：

* 用户直接讲话打断 AI
* 点击中间区域停止播放

---

# 五、打断逻辑

AI讲话时：

中间区域变为可点击区域。

例如：

```
🔇        ●        ❌
          ↑
       点击停止
```

功能：

* 点击 → 停止 AI 播放
* 用户讲话 → 自动打断

---

# 六、字幕设计

原则：

复用原聊天字幕区域。

不新增：

```
字幕
状态文字
语音动画
按钮
```

多层堆叠。

字幕：

* 最大两行
* 固定高度
* 不因语音状态变化移动

状态提示：

不长期显示。

只在状态切换时短暂显示：

例如：

进入语音：

```
正在聆听...
```

AI讲话：

```
奈可正在说话
```

显示 1~2 秒后隐藏。

---

# 七、不采用方案

禁止：

### 大面积电话模式

例如：

```
角色

语音波形

按钮区域
```

原因：

* 遮挡 Live2D
* 降低陪伴感
* 更像会议软件

禁止：

### 传统音频柱状波形

例如：

```
▂▅▇▃▆
```

原因：

* 工具感强
* 不符合猫娘陪伴风格

---

# 最终效果目标

用户看到的是：

> “猫娘正在听我说话”

而不是：

> “我正在操作一个语音助手”。

核心 UI：

```
🎙️        · · ● · ·        ❌
```

通过柔和粒子呼吸动画表达：

* 监听
* 思考
* 讲话
* 可打断

同时保证 Live2D 始终是视觉中心。

注意！现在 的挂断按钮是红色的，不是红色是背景和麦克风的一致，只不过是红色x
