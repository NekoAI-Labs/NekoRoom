# NekoChat Patch Version Update Requirements

## 目标

完成本次版本功能调整，优化本地模型默认体验，并增加性能信息分享能力。

---

## 1. 默认模型调整

### 修改内容

* 将应用默认加载模型切换为训练好的 **Neko 猫娘模型**。
* 新安装用户首次进入时：

  * 默认选择 Neko 模型。
  * 不再默认使用 MiniCPM 原始模型。

### 注意

* 保留已有模型切换能力。
* 已下载用户的模型选择状态不要强制覆盖。

---

# 2. 本地模型多轮对话开关

## 背景

本地小模型多轮能力有限，容易出现：

* 上下文污染
* 人设漂移
* 回复质量下降

因此默认关闭。

---

## 功能设计

新增设置项：

路径：

```
设置 → 开发者模式
```

新增：

```
本地模型多轮对话
```

选项：

```
关闭（默认）
开启
```

默认：

```
false
```

---

## 行为

关闭时：

* 每次请求只发送当前用户输入
* 不携带历史聊天记录

开启时：

* 使用现有多轮上下文逻辑
* 保持当前行为不变

---

TTS Quality 默认值

# 4. 默认文本模型排序调整

## 修改模型列表默认排序

本地文本模型按照精度排序：

```
MiniCPM FP16
↓
MiniCPM Q8
↓
MiniCPM Q4
...
```

要求：

* 精度高的模型优先展示
* 默认推荐 FP16
* 不改变用户已经选择的模型
